=====================================================
LARAVEL STACK INSTALLATION GUIDE (DOCKER COMPOSE)
=====================================================

This guide assumes you have placed all three required configuration files (docker-compose.yml, Dockerfile, default.conf) in the correct directories (src/, docker/php/, nginx/conf.d/).

-----------------------------------------------------
I. UNIVERSAL PREREQUISITES AND STRUCTURE
-----------------------------------------------------

PREREQUISITES:
- Docker Engine and Docker Compose (or Docker Desktop on Windows).
- Git (Optional, but recommended for cloning the repository).

FILE STRUCTURE:
- Ensure the project directory includes the following folders:
  /src
  /docker/php
  /nginx/conf.d

-----------------------------------------------------
II. DEPLOYMENT GUIDE FOR LINUX / CASAOS
-----------------------------------------------------

1. NAVIGATION: Use SSH/Terminal to navigate to your project directory on the server (e.g., /DATA/AppData/your-project/).

2. DEPLOYMENT COMMAND: Execute the command to build the custom PHP image and start all services:
   docker compose up -d --build

3. VERIFICATION: Ensure all containers are running:
   docker ps

-----------------------------------------------------
III. DEPLOYMENT GUIDE FOR WINDOWS
-----------------------------------------------------

1. PREREQUISITES: Ensure Docker Desktop is running.

2. NAVIGATION: Open PowerShell or Command Prompt and navigate to your local project directory (e.g., C:\Users\user\project\).

3. DEPLOYMENT COMMAND: Execute the same universal command:
   docker compose up -d --build

-----------------------------------------------------
IV. POST-DEPLOYMENT SETUP (REQUIRED FOR ALL HOSTS)
-----------------------------------------------------

Once all containers are UP, you must install Laravel's dependencies.

1. ACCESS PHP CONTAINER: Log into the running PHP container using the service name 'php':
   docker exec -it app-php /bin/sh

2. INSTALL DEPENDENCIES: Inside the container, run Composer and generate the application key:
   composer install
   php artisan key:generate
   
3. EXIT:
   exit

-----------------------------------------------------
V. ACCESS & USAGE
-----------------------------------------------------

Your application is ready:

- Laravel App (Nginx): http://localhost
- phpMyAdmin: http://localhost:8080
