=====================================================
LARAVEL DOCKER STACK — INSTALLATION GUIDE
=====================================================

This guide explains how to deploy the Laravel LEMP stack using Docker Compose on Linux, CASA OS, or Windows.

-----------------------------------------------------
I. REQUIRED SETUP & DIRECTORY STRUCTURE
-----------------------------------------------------

PREREQUISITES:
- Docker Engine + Docker Compose (Linux & CASA OS)
- Docker Desktop (Windows)
- Git (optional)

PROJECT STRUCTURE:
Make sure your directory contains:
  src/               ← Your Laravel project
  docker/php/        ← Dockerfile
  nginx/conf.d/      ← default.conf
  docker-compose.yml ← main stack file

-----------------------------------------------------
II. DEPLOYMENT ON LINUX / CASA OS
-----------------------------------------------------

1. Navigate to your project directory:
   Example (CASA OS):
   cd /DATA/AppData/your-project/

2. Start the stack and build the PHP image:
   docker compose up -d --build

3. Verify the containers:
   docker ps

-----------------------------------------------------
III. DEPLOYMENT ON WINDOWS
-----------------------------------------------------

1. Make sure Docker Desktop is running.

2. Open PowerShell and go to your project folder:
   cd C:\Users\YourName\your-project\

3. Run the stack:
   docker compose up -d --build

-----------------------------------------------------
IV. POST-DEPLOYMENT SETUP (REQUIRED)
-----------------------------------------------------

1. Enter the PHP container:
   docker exec -it app-php sh

2. Install Laravel dependencies:
   composer install
   php artisan key:generate

3. (Optional but recommended)
   php artisan storage:link
   php artisan migrate

4. Exit:
   exit

-----------------------------------------------------
V. ACCESSING YOUR APPLICATION
-----------------------------------------------------

Laravel Application:
  http://localhost:8081

phpMyAdmin:
  http://localhost:8080

=====================================================
Deployment complete.
